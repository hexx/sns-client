# 引用カードはインライン展開＋外部リンクとし、アプリ内スレッドビューは持たない

quote card のタップ遷移先として、アプリ内のスレッド/詳細ビューを新設せず、**その場でのインライン展開（全文・全 Media・stats・日時）と Provider Web への外部リンク（`Post.url`）の2手段**で確定する。引用先への返信・リアクション等の操作も一切載せない。スレッドビューは reply 構造（root/parent）の正しい解釈と全 Provider での取得 API 対応が要る別機能であり、「引用を表示したい」という本題の依存にすべきでないため。詳細: [quote-display-spec.md](../quote-display-spec.md)。

## Considered Options

- **アプリ内スレッドビューを開く** — 最もリッチだが、未実装機能の設計・実装が引用表示の前提になり、スコープが数倍に膨れる。将来スレッドビューができれば「カードクリック = スレッドビュー」へ差し替え可能で、本決定はその布石と矛盾しない。
- **外部リンクのみ** — 実装は最小だが、全文を少し見たいだけでアプリ離脱を強い、X 系クライアントの引用カード UX からも外れる。
- **クリック不可（表示のみ）** — 現行のまま。5行截断を導入すると「全文を見たい」出口が一切なくなり、改悪になり得る。

## Consequences

- `Post.url?: string`（permalink、BFF 生成）が新設される。当面の消費者は quote card の外部リンクのみだが、将来トップレベル投稿やスレッドビューでも再利用できる。
- 将来スレッドビューを実装した場合、quote card のクリック挙動を「展開」から「スレッドビューへ遷移」に変更する再審が発生する。その際も外部リンクアイコンは残す。

## 再審（thread-view-spec による決着）

スレッド表示機能が導入されたため、上記の再審宿題を**変更あり**で決着する（[thread-view-spec.md §7](../thread-view-spec.md)）。

- quote card **本体のクリック＝引用先の Thread へ遷移**に変更する。「もっと見る」インライン展開トグルと ↗ 外部リンクは別操作として残す（`stopPropagation` で遷移に貫通しない。上記「外部リンクアイコンは残す」は維持）。
- 遷移先は引用先自身のスレッドで、通常の Thread と同様に操作可能。カード自体が表示専用（操作を載せない）という本 ADR の原決定は維持する。
- `quoteUnavailable`（取得不能）は遷移先が無いので入口を付けない。対象は bsky / misskey のみ（nostr 投稿に quote は無い）。
- 本 ADR のタイトル「アプリ内スレッドビューは持たない」は決定時点の状態を指す。スレッドビューは後に独立機能として実装された（thread-view-spec.md）。
