# カードメタ行 仕様書（ヘッダー3行化＋公開範囲バッジのアイコン化）

> 複数 SNS を1画面で扱う PWA クライアント（[sns-client-spec.md](./sns-client-spec.md)）における、
> **カードヘッダーのメタ行再編**の確定仕様。[name-display-spec.md](./name-display-spec.md)（2行ヘッダー化）
> の続きとして、2行目に詰め込まれていた補足情報を「投稿者情報」と「帰属情報」に分割し、
> 公開範囲バッジをアイコン化する。
> 作成: grilling セッション（全3問合意）に基づく。
> 関連: [name-display-spec.md](./name-display-spec.md) / [deck-view-spec.md](./deck-view-spec.md)（帰属バッジ §5）/
> [misskey-channel-display-spec.md](./misskey-channel-display-spec.md)（チャンネルチップ）。
> 用語は [CONTEXT.md](../CONTEXT.md) 参照。

## 1. 背景・目的

- name-display-spec による2行ヘッダー化の後、2行目が
  「`@handle` + 公開範囲テキスト + チャンネルチップ + プロバイダバッジ」の4要素で長く窮屈になった
  （例:「@yczas1031 ローカルのみ misskey子育て部 Misskey · ホーム」）。
- 根本原因は、**「誰が」（handle・公開範囲）と「どこから」（チャンネル・由来リスト）という
  性質の異なる情報が1行に混在**していること。
- また「ローカルのみ」のテキスト（5文字）は、同じ情報が `title` ツールチップで既に提供されており、
  横幅に対する情報効率が悪い。

## 2. スコープ

### 今回（確定）
- **ヘッダーの3行化**（投稿者行 / 帰属行への分割）。
- **公開範囲バッジのアイコン化**（テキスト廃止、`localOnly` に 📍 新設）。
- **チップの max-width 調整**（12em → 10em）とホバーフィードバック。

### 対象外
- プロバイダバッジの短縮・プラットフォーム別色分け（deck-view-spec §5 の文言を維持）。
- 公開範囲のテキスト表示オプション（方針として採用しない）。
- 引用カードへのメタ情報追加（元々バッジ・チップを持たないため不変）。

## 3. レイアウト（ヘッダー3行化）

name-display-spec §3 の2行構成を、以下のように3行へ再編する:

```
1行目: [avatar] 名前・・・・・・・・・・・・・・時刻（右端）
2行目: [avatar] @handle  [公開範囲アイコン]
3行目: [avatar] [チャンネルチップ] [プロバイダバッジ]
```

- **2行目（投稿者行）**: `@handle` と公開範囲アイコン。投稿者そのものに関する情報。
- **3行目（帰属行）**: チャンネルチップ → プロバイダバッジの順（具体 → 汎用で自然に読める。現順序を維持）。
  「この投稿がどのコミュニティに属し、どのカラムのどのソースから来たか」を示す。
- avatar は3行にまたがって縦中央（`align-items: center` 維持）。
- 行ごとに `.author-line` を用いる（name-display-spec §3 の構造を拡張）。
- 公開範囲アイコンもチャンネルチップも無い投稿では、該当行は描画しない（空行は生まれない）。
  ただしプロバイダバッジはデッキ表示では常に存在するため、通常は3行になる。

## 4. 公開範囲バッジのアイコン化

`VisibilityBadge`（PostCard.tsx）を以下のように変更する:

| 状態 | 現行 | 変更後 |
|---|---|---|
| visibility=home | 🏠 | 🏠（不変） |
| visibility=followers | 🔒 | 🔒（不変） |
| visibility=specified | ✉️ | ✉️（不変） |
| localOnly=true | テキスト「ローカルのみ」 | **📍**（新設） |
| visibility=public かつ localOnly=false | 非表示 | 非表示（不変） |

- **テキスト表示は廃止**する（「ローカルのみ」文字列を出さない）。
- 説明は `title` ツールチップで提供する: `localOnly` なら「ローカルのみ」、
  さもなくば公開範囲名（home/followers/specified）。
- visibility と localOnly は併存しうる（例: 🔒 + 📍）。その場合は両アイコンを並べて表示し、
  ツールチップは「ローカルのみ・フォロワー」のように合成する。

## 5. チップの調整

- **max-width**: チャンネルチップ・プロバイダバッジとも `12em` → `10em`。
  はみ出す名前はチップ内で省略（`text-overflow: ellipsis`）し、`title` ツールチップでフルネームを表示する
  （チャンネルチップは既存機構、プロバイダバッジにも `title` を追加する）。
- **ホバーフィードバック**: 両チップに `transition` 付きのホバー時枠色変化を追加し、
  ホバー可能（ツールチップあり）であることを示唆する。
- **文言**: プロバイダバッジは「プラットフォーム名 · ソース名」形式を維持する（deck-view-spec §5）。
