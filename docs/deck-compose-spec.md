# デッキ UI からの Compose（新規投稿）仕様書

> [デッキ UI 仕様書](./deck-view-spec.md) で対象外とされていた **新規投稿（Compose）** を、
> デッキ UI から行えるようにする拡張の確定仕様。
> 作成: grill-with-docs セッション（全6問合意）に基づく。用語は [CONTEXT.md](../CONTEXT.md) 参照。

---

## 1. 背景・目的

- デッキ UI（deck-view-spec）は v1 で「返信・引用・新規投稿」をまとめて対象外としていた。
- 利用者から「デッキ表示のまま新規投稿（ポスト）を作成したい」という要望がある。
- 既存のスマホ/タブ UI には投稿モーダル（`Compose`）が既に存在する。本拡張はこれを**デッキ UI に接続する**ものであり、投稿機能そのものの新規設計ではない。

## 2. スコープ

### 今回（確定）
- **新規投稿（Compose）のみ**。デッキ UI から既存の `Compose` モーダルを起動し、新しい Post を作成・送信する。
- 起動導線: **固定フロートボタン**（デッキ表示時のみ表示）。
- 投稿成功時の**トースト通知**。

### 対象外（v1）
- デッキのカードからの **reply（返信）/ quote（引用）**。引き続き対象外（必要ならスマホ/タブ UI を利用）。
- キーボードショートカット（`n` 等）からの起動。
- 投稿先 Provider のデッキ固有の既定値。
- 投稿後のカラム強制リフレッシュ（ポーリング模型は維持）。

## 3. 用語

- **Compose**: 新しい Post を作成する行為、およびその UI（投稿モーダル）。CONTEXT.md に定義済み。本仕様では「新規投稿」を Compose と呼ぶ。

## 4. UI

### 起動導線（固定フロートボタン）
- デッキ表示中、画面右下に固定配置（`position: fixed`）のボタン（例:「✏ 新規投稿」）を表示する。
- カラムの横スクロールに依存せず常時見える。
- デッキ表示（画面幅 ≥1024px）のときのみ表示され、タブ UI では既存の Compose 導線（Timeline 上のボタン）をそのまま使う。
- ボタン押下で `Compose` モーダルを開く。

### Compose モーダル
- 既存 `Compose` コンポーネントを**無改造で再利用**する。
  - プロバイダ切替（Bluesky / Misskey / Mastodon）、文字数カウンタ、画像添付（最大4枚）、CW、Misskey の visibility / ローカルのみ、Bluesky の言語指定——すべて既存挙動のまま。
- 投稿先 Provider の既定: 既存の `localStorage`（キー `compose-target`）による前回選択の記憶をそのまま利用。デッキ固有の既定は設けない。

### 投稿成功後のフィードバック
- 送信成功時に**トースト**（例:「投稿しました」）を表示する。
- デッキは複数カラムを常時監視する UI であり、自分の投稿がどのカラムの Source にも流れない（またはポーリング間隔まで表示されない）ケースがあるため、成功を明示的に通知する。
- カラムの強制リフレッシュは行わない。新着は既存のポーリング（Misskey 15秒 / Bluesky 30秒）と新着ピルの方針に従う（deck-view-spec §3 更新モデル）。

## 5. 実装方針

- **状態所有**: Compose の開閉状態（`{ open, replyTo?, quote? }`）は引き続き `App.tsx` が単一で所有する（タブ UI と同一の単一ソース）。
- **ガード解除**: `App.tsx` の `{!isDeck && compose.open && ...}` ガードを外し、デッキ表示中でも `Compose` を描画可能にする。
- **導線接続**: `Deck` コンポーネントに `onCompose` プロパティを追加し、フロートボタンから `App` の `setCompose({ open: true })` を呼ぶ。
- **成功時処理**: `onPosted` でトースト表示用の状態をセットする（タブ UI の `justPosted` ハイライトとは別に、デッキではトーストを用いる）。
- 変更箇所は「ガード解除 + `Deck` への `onCompose` 追加 + フロートボタン + トースト」に限定する。`Compose` 内部には一切手を入れない。

## 6. 非目標（v1）

reply / quote の起動／キーボードショートカット／デッキ固有の Provider 既定／投稿後のカラム強制リフレッシュ／スマホ向けデッキ最適化。
